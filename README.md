# Modern-Web-Application

## Domain language

- Course Department: the discovery category attached to Course records and used for browsing course-led departments.
- Tutor staff affiliation: the staff member's academic unit or affiliation shown on Tutor profiles and admin Tutor records.
- Tutor records still store this value in the existing `department` field for compatibility; user-facing Tutor copy should call it Staff affiliation or Academic Unit, not Course Department.
